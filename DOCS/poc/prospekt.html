Firebase Setup
Connect your free database — one time only

One-time setup required

Firebase is free and takes 5 minutes to set up. Once done, all client logins, leads, and activity sync across devices automatically. You only do this once.

Step by Step
1
Go to Firebase Console
Visit firebase.google.com and click "Get Started". Sign in with your Google account.
2
Create a new project
Click "Add project" → Name it "Prospekt" → Disable Google Analytics (not needed) → Create project.
3
Enable Firestore Database
In your project → Build → Firestore Database → Create database → Start in test mode → Choose a region (eur3 or us-central1) → Enable.
4
Get your config values
Project Settings (gear icon) → General → Your apps → Click web icon (</>) → Register app → Copy the firebaseConfig object values below.
5
Paste your config here
Fill in the fields below and click Save. The app will immediately connect to your Firebase database.
Until Firebase is configured, the app runs in local mode (data stored in this browser only). Set up Firebase to get real cross-device sync and client management.
