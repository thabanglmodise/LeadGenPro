API Setup
Connect your data sources
Google Places API (Real Company Data)
1
Create a Google Cloud Project
Go to console.cloud.google.com → New Project. Name it anything (e.g. "LeadAI").
2
Enable Places API
APIs & Services → Enable APIs → Search "Places API" → Enable it. Also enable "Maps JavaScript API".
3
Get API Key
APIs & Services → Credentials → Create Credentials → API Key. Copy it and paste below. Google gives you $200 free credit/month — enough for thousands of searches.
Anthropic API (AI Scoring + Email Drafting)
Claude AI analyses each lead and scores them hot/warm/cold based on your offering. It also writes personalised emails. Each client gets their own free API key from anthropic.com — sign up is free and includes $5 credit.
1
Get Your Anthropic API Key
Go to console.anthropic.com → Sign up free → API Keys → Create Key. $5 free credit on signup = hundreds of lead scores + email drafts.
Gmail (Send Emails)
1
Enable Gmail App Password
Go to your Google Account → Security → 2-Step Verification (enable if not on) → App Passwords → Generate password for "Mail". Copy the 16-character code.
The app opens Gmail with your email pre-filled. You click Send — takes 2 seconds. For fully automated sending (zero clicks), a backend server is needed (Phase 2).
